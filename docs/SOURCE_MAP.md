# 통합본 구성

2026-10-29 로컬 작업본을 기준으로 Jetson, STM32, 대시보드를 이 저장소의 `main`에 모았습니다. 원본 저장소의 커밋 이력은 원본에 남아 있으며, 이 저장소는 정리한 소스의 새 이력을 시작합니다.

| 통합 위치 | 원본 기준 |
|---|---|
| `code/` | `rail_robot`의 `rust_detect`, 기준 커밋 `866dcda`와 이후 로컬 수정 |
| `stm_code/code/encoder/` | `rail_robot`의 `stm_code`, 기준 커밋 `11885fc`와 구간 수 수정 |
| `rail_dashboard/` | 대시보드 작업본, 기준 커밋 `73732d0` |

Jetson의 검사·보고서·통신 코드와 관련 시험에 있던 로컬 수정, STM32의 기본 검사 구간을 6개로 조정한 수정을 포함했습니다. 새 저장소를 만들기 위해 원본 작업본의 변경을 되돌리거나 원본 브랜치에 커밋하지 않았습니다.

공개본에서는 다음 부분을 정리했습니다.

- 루트, Jetson, STM32, 대시보드 README를 현재 코드에 맞춰 작성했습니다.
- 온라인 Firebase 화면의 웹 연결 설정을 환경변수로 옮기고 예제 파일을 추가했습니다.
- 접근 규칙의 운영 관리자 이메일을 예시 주소로 교체했습니다. 사용하는 서버에 맞는 관리자를 별도로 지정해야 합니다.
- 통합 폴더 구조에 맞춰 대시보드의 검사 결과·가상 시험 경로를 조정했습니다.
- 특정 편집 환경에 의존하던 웹 실행 구성을 일반 Node/npm 경로로 정리했습니다.
- 실행에 필요한 STM32 드라이버와 라이선스, 셸 실행 권한을 유지했습니다.

실제 인증 파일, 모델 가중치·엔진, 학습 데이터, 검사 기록, 음성 파일, 가상환경과 빌드 결과는 게시 대상에서 제외했습니다. 이 정리는 코드 저장소에 한정하며 Jetson 배포, 보드 플래시 또는 Firebase 운영 서버 변경을 수행하지 않았습니다.
